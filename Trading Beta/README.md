# Trading Beta

Trading Beta is the legacy first TradingLab project. It contains the original root-level research code, data, dashboards, notebooks, scripts, Power BI workbooks, and supporting notes.

This project is retained for reference and historical reproducibility. New work should normally target `Regime trading`, `Swing`, `Pattern Trading`, or `Intraday` instead.

The contents have not been deleted or rewritten as part of the repository reorganization; only their location was consolidated under this folder.
